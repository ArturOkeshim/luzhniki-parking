# Локальная тестовая версия абонементов — V6.8

Это полный комплект сайта `parking.luzhniki.ru`, а не обновление отдельных файлов.
Установщик подходит как для уже работающего сервера, так и для чистой установки приложения.
Файлы Bitrix и CRM этим комплектом не изменяются.

## Локальный запуск в Windows

Откройте PowerShell в каталоге комплекта и выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\START-LOCAL.ps1
```

Страница откроется по адресу `http://127.0.0.1:4194/parking-subscription`.

Скрипт отключает проверку TLS только у локального дочернего процесса Node, потому что
`crm.luzhniki.ru` на дату подготовки отдаёт просроченный сертификат. Это исключение не
включено в приложение и не применяется к production-запуску. После обновления
сертификата строку `NODE_TLS_REJECT_UNAUTHORIZED` из `START-LOCAL.ps1` нужно удалить.

По той же причине локальный режим временно выполняет операции контактов, заказов и
платежей через штатный Bitrix REST напрямую. В production эта ветка отключена и
сохраняется основной маршрут VibeCode. После обновления сертификата нужно убрать
локальное исключение из `site/app/lib/vibecode.ts`.

## Что исправлено

- платёжная ссылка строится на сервере сайта сразу после создания платежа; ожидание публичной ссылки Bitrix исключено;
- подписанный шлюз `/local/promo-api/pay.php` задаёт возврат на `parking.luzhniki.ru/parking-subscription`, поэтому служебная страница Bitrix после оплаты не должна показываться;
- при подготовке оплаты покупатель видит страницу ожидания «Лужники», а не пустую вкладку `about:blank`;
- ключ подписи `pay.php` отделён от API-ключа промокодов и сделок, поэтому ротация API-ключа не приводит к ошибке 403 на оплате;
- границы календаря приходят с серверного API в часовом поясе `Europe/Moscow`: дата и часовой пояс телефона покупателя полностью игнорируются;
- пока сервер не вернул московскую дату, календарь и переход к оплате заблокированы — возврата к локальному времени устройства нет;
- абонемент действует ровно 30 календарных дней включительно: дата окончания равна дате старта плюс 29 дней;
- после подтверждения оплаты покупатель сразу возвращается на страницу сайта с сообщением об успешной оплате;
- формирование кассового чека больше не блокирует возврат покупателя;
- восстановлено согласие на рекламные и информационные сообщения;
- политика и согласие на обработку персональных данных открываются по утверждённым внешним PDF-ссылкам;
- обновлены основные правила, предупреждения, формулировки согласий и названия полей тарифов;
- в карточках тарифов явно указаны периоды въезда и выезда, максимальная длительность визита и крайнее время выезда;
- повторяющиеся предупреждения перенесены из отдельных тарифов в общий блок правил;
- цена тарифа «Дружба · будни» сохранена без изменения: 6 000 ₽;
- цена тарифа «Дружба · будни и выходные» сохранена: 8 000 ₽;
- сохранены действующие тарифы, промокоды, защита контактов, одна сделка/заказ/платёж и 15-минутный срок платёжной ссылки.

## Требуется перед публикацией

Файл `site/public/documents/parking-tariffs-2026.pdf` остался из предыдущей версии. Для выполнения замечания по документам его нужно заменить действующей редакцией Приложения № 3 с изменениями от 07.09.2026. В полученных материалах новой редакции PDF нет.

## Состав

- `site/` — полный исходный код приложения;
- `site/SERVER-CONFIG-WITH-KEYS.env` — видимая приватная готовая серверная конфигурация со всеми ключами;
- `site/.env.production` — копия конфигурации для совместимости;
- `site/deploy/` — systemd unit, проверка конфигурации и пример Nginx;
- `install.sh` — установка, резервная копия, проверка и автоматический откат;
- `INSTALL.md` — пошаговая инструкция для копирования команд.
- `TEXTS-REVIEW.html` — самодостаточный файл со всеми текстами страницы для согласования.
- `START-LOCAL.ps1` — запуск локальной версии в Windows с комплектной конфигурацией.

## Важно

Архив содержит секреты подключения к действующим сервисам. Храните его с правами `600`, не размещайте в публичном каталоге сайта и не отправляйте третьим лицам.

При существующей установке сохраняются текущий `/opt/luzhniki-parking-subscription/app/.env` и полный резервный архив приложения. При чистой установке используется комплектный `site/SERVER-CONFIG-WITH-KEYS.env`.

Установщик не меняет Nginx автоматически. Если домен уже работает, его конфигурация сохраняется. Для нового сервера пример находится в `site/deploy/nginx-parking.luzhniki.ru.conf.example`.
