# Абонементы на проезд «Лужники»

Исходный код production-сайта `https://parking.luzhniki.ru/` версии 6.0.

Заказы, корзина и платежи создаются через VibeCode Bitrix24, сделки обновляются входящим REST-вебхуком, а `/local/promo-api/index.php` обслуживает одноразовые промокоды. Ядро Bitrix не изменяется. Порядок установки, резервного копирования, автоматической проверки и отката описан в корневом `README.md`; установку выполняет корневой скрипт `02-install-site.sh`.

Настройки берутся из существующего файла `/opt/luzhniki-parking-subscription/app/.env`. В поставку включён только пустой шаблон `.env.example`; действующие секреты в архив не входят.
